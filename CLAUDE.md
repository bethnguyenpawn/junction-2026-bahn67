# CLAUDE.md

Team project for Junction 2026, **Spread** challenge by Bahn Express: a Python program that dispatches car transports for one simulated week. Score = gross margin; ≥ 90% of won orders on time or unranked. The final is **Sunday 15 Nov 09:00 (moved from 08:00), level 8, live clock, ~34 min**; last test final Sun 01:00. Only the final decides the top 10; after that the jury judges elegance, clarity, creativity and robustness, not margin.

Read first: `PROGRESS.md` (status, next steps), `LESSONS.md` (every experiment with numbers), `docs/CHALLENGE_SUMMARY.md`. Authoritative rules: `docs/RULES.md` > `docs/HANDBOOK.md` > other docs. `docs/API.md` and `docs/openapi.json` for routes. Kit types: `.venv/lib/python*/site-packages/spread/types.py` — use exact field names from there, never guess.

## Commands

```bash
.venv/bin/python main.py --level 8 --seed l8-a --preset l8_lane [--set name=value ...]   # one week
.venv/bin/python evaluate.py --level 8 --preset l8_lane [--seed-prefix l8x] --set ... --note "..."   # 10-week benchmark, ~4 min
.venv/bin/python analysis/orders.py --note "..."     # per-order late%/margin of a logged run (caches results/raw/)
.venv/bin/python main.py --final --preset l8_lane        # the final
.venv/bin/python -m unittest discover -s tests       # offline tests: run before every commit
~/.vscode/extensions/charliermarsh.ruff-*/bundled/libs/bin/ruff format .   # style (ruff.toml, 120 cols); the user's editor formats on save
```
Scripts load `.env` themselves (`main.load_env`). Use `.venv/bin/python`, not system python (3.15 system, kit in venv). Run benchmarks **one at a time in the foreground** (detached background `&` runs were blocked by the permission classifier); a long one may be auto-moved to background — wait for its notification.

## Code map

- `main.py` — `play_practice` (advance loop, wakes on `dispatch.WAKE_ON` events, plus every `tick_min` when the ladder is on) and `play_final` (rebuild via `Desk.rejoin`, then WebSocket stream; `guarded` logs and skips a failing event or tick). `play_practice_safely` (also used by evaluate.py) rebuilds and continues after HTTP 502-504 / timeouts; `--world ID` continues a stopped practice or ranking world. `--board` creates a RANKING run: only the user runs it, never Claude without explicit OK.
- `dispatch.py` — `Desk`: state + `handle(event)` → actions in `outbox`. Fee decisions: `fee_schedule`, `steep_schedule`, `fees_for`, `ladder_mult`, `tick` (reprices unbooked non-urgent gigs upward). Note reader `window_from_note`. `drivers_near(roster, places)` = drivers living within 30 km of each place (built by `main.load_near` only when a rule needs it: one extra read). `Desk.offer` = direct offers (off; tested useless). `Desk.pair` = two-car gigs at win time (off). `Desk.plan` (batch planning): `plan_pairs` (pairs of held cars) or, with `chain_max>=2`, `plan_chains` → `build_chains` (greedy, round trips first) + `chain_fits` (deadlines, slots, 12 h) over held cars and posted unbooked one-car gigs (`withdraw_now` confirms each withdraw); `chain_replan` (off, worse), `chain_private` / `chain_charging` (private addresses / charging cars in chains, off, Exp. 45; `span` counts plates and charging minutes), `chain_fee_step` (untested). `chain_partners` + `fit_cut` (cheaper quote when a request could chain with a held or posted car, off, Exp. 45). `backlog_h` (count only driverless cars due within h hours, off, Exp. 45). `offer_next` + `next_offer_mult` (offer the next car to a driver who just booked, off, Exp. 46: 1 of 84 accepted). `match_pairs` = Edmonds' maximum matching (from the codex branch, `maximum_cardinality_matching`): `pair_match=1` in `plan_pairs` (`l8_plan_match`: +3.2% over `l8_plan`), `chain_match=1` seeds `build_chains` (−4.6%, off). `analysis/sharing.py` = cars shared vs. alone. `Desk.learn` = win-rate steering (off, `adapt_target`). `Desk.ease` = fee factor for easy cars (off). `fees_for(stops)` builds every gig's schedule. `Desk.stops_for` = `stops_for` with the note's facts, the clock and roads (`charge_km`: charging stop only on routes > 200 km). `Desk.cancel` posts again the other cars of a gig the world withdrew for a cancelled order (RULES; Exp. 60). `raise_every` = slower raises for cars with time (`slow_every_min`, off, Exp. 57).
- `notes.py` — `read(note, arrived_at)` → `Facts` (ready, deadline, delivery_close, pickup_hours, plates, manual): typo correction to a keyword list, then sentence by sentence (role + last undenied day/time; a correction sentence keeps the other half). `due()` = the earlier deadline incl. closing time; `open_interval()` = the first reachable weekday interval of the pickup site's real hours. Used with `note_reader=1` by `stops_for` (windows, `withPlates`), `Desk.manual` (audience), `Desk.last_pickup` (holds, our own deadline warning in `tick`) and `pricing.slack`. Scored on revealed truth (`reveal.orders[].legs[]`): all 5,790 noted cars right except 5 plates/manual false alarms.
- `pricing.py` — `typical_fee(request, params)`: with `fee_lane` the typical fee averaged (log) with its lane's mean from `fees.json` (`lane_key`; rebuild with `analysis/typical.py` after new cached weeks); `fees_for` builds every fee on it. `quote(request, level, params, Situation)`: levels 1–3 list price (**no quote = declined**). `opt=1`: per-option expected-profit price from the fitted win/late logistic models (`best_price`; coefficients `win_*`, `late_*` in Params, fitted by `analysis/winmodel.py` / `latemodel.py`, numpy needed only there). Flat rules (`flat_mult`), levels 4+: list × (`quote_mult` + `backlog_k` × backlog), decline (10× list) over `decline_km` or more than `max_legs` legs (trade-ins), offer only options with ≥ `min_slack_h` slack. Optional: `dest_k` (+ the competitor's offset for the delivery place from `lanes.json`, refit with `analysis/lanes.py`), `dense_n/dense_cut` (cheaper where many drivers live near the pickup), `private_add` (private addresses). Off: `opt_trust_gain` (value of building trust, Exp. 29), `monday_add` (Exp. 32), `return_mult` (return-trip offers, `Desk.offer_return`, Exp. 33), `outage_add/_n/_rate/_km` (price up where we win most quotes today = competitor outage, `Desk.outage_near`, Exp. 34: −€1.9k at +0.3, neutral at +0.1), `war_cut/_n/_rate` (cheaper on the detected price-war day, `Desk.price_war`, Exp. 35: neutral), `trust_w`, `later_mult`, `adapt`, `cost_k`, `explore_lo/hi` (research: random prices).
- `market.py` — `Market`: the competitor's level move this week and today (x list), MAP-fitted from our own answers (`Desk.quote` stores price − delivery offset and trust share, `Desk.learn` adds the answer). Constants from `analysis/competitor.py` (offline, cached weeks). `market_k` (off) adds `market_k` × move to the price, within `market_lo`..`market_hi` (Exp. 44; replaced Exp. 31's `market_lr`). A restart starts the estimate from the usual level.
- `analysis/orders.py --note "..."` — per-order late%/margin by distance, option, day, hour, town. `analysis/market.py --note "..."` — win rate by price, drivers near pickup/delivery. `analysis/common.py` loads worlds by log note (caches events, reveal, snapshot, driver list).
- `config.py` — `Params` dataclass; every tunable number, used ones first, "tested and off" ones last (with their LESSONS experiment number). Defaults reproduce the kit starter exactly. `--set k=v` overrides.
- `evaluate.py` — seeds `l{level}-a..` (`--seed-prefix l8x` for the holdout set), ≤ 4 parallel worlds (other 4 slots for teammates), checks open-world count first, waits up to 5 min for a free slot on HTTP 409, appends JSON line (commit, params, per-seed scores).

## Invariants / gotchas

- Defaults must stay identical to the starter (−€3,220.38 on `l1-a` level 1). If you change default behaviour, change the default in `Params` deliberately and note it.
- Level 1 gigs accept **one fee step**; multi-step schedules only from level 2. Our ladder works around this with `reprice` (allowed on any unbooked gig).
- From level 2 drivers learn our raises (running mean of booked/first-viewed fee and wait time) — level-1 ladder results may not transfer.
- Money is integer cents, times integer world minutes (Monday 00:00 = 0). The client rejects floats with fractions: always `int(... + 0.5)`.
- Max 50 actions per request, 8 unfinished practice worlds per team (shared with teammates), rate limit shared per key.
- Drop duplicate events by `seq`. 502/503/504 = server restarting → `Unreachable`; wait, re-read state, continue.
- Final: 20 actions/s, 50 reads/s, clock runs by itself; decision code must be fast and clock-independent.

## Rules of conduct

- **Never print, log or commit `SPREAD_KEY`.** `.env` is git-ignored; don't `cat` it (check with grep for the placeholder instead).
- **Never create ranking runs (`board: true`) without the user's explicit OK.** They're limited (5/level/round), can't be revealed, deletion still counts.
- Don't delete worlds that aren't ours / still running for teammates. Our evaluate runs finish their worlds.
- **Experiments:** one parameter change at a time, same 10 seeds, then add a row to `LESSONS.md` (idea / why / effect). Keep a change only if margin rises AND every week stays well above 90% (target worst week ≥ 91%).
- **Git:** remote is SSH with a YubiKey → the user runs `git fetch` / `git push` themselves (`! git ...`); merge locally after their fetch. We work on branch `otso/level1-baseline` (no PR for now); don't commit to `main` directly. Commit only when asked. Remote: `git@github.com:bethnguyenpawn/junction-2026-bahn67.git`.
- Report numbers, not prose. The user prefers short, plain explanations.
